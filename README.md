# Projeto Investimento

Plataforma de organização financeira pessoal desenvolvida com React, Node.js e Microsoft SQL Server.

## Objetivo

Permitir que usuários organizem informações profissionais, rendas, contas financeiras, despesas, parcelas, reservas e investimentos.

## Stack planejada

- React
- TypeScript
- Node.js
- Fastify
- Prisma
- Microsoft SQL Server
- Python para futuras automações

## Banco local

- Banco: FinanceApp

Credenciais, senhas e variáveis de ambiente não são versionadas.

## Status

Projeto em desenvolvimento.
